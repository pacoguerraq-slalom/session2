# TODO Application Functional Requirements

- Users can create tasks.
- Users can edit existing tasks.
- Users can delete tasks.
- Users can mark tasks as completed or incomplete.
- Users can assign a due date to a task.
- Tasks are sorted by due date, with the nearest due dates first.
- Users can set task priorities: High, Medium, or Low.
- Users can filter tasks by completion status and priority.
- Task data is saved and remains available when the application is reopened.
